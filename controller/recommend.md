# 角色


## 运营者

平台运营者负责免费资产以及付费资产的管理和运营，并提供AI制作相关的API接入，发布AI Token 供内容制作者创作使用。创作者可以按月订阅Token或者按量订阅token
实现辅助制作。

前期资产可以全部免费，后期逐步提供付费资产功能，付费资产由运营者和作者共建。
关于付费资产，平台鼓励创作者上传自己的优秀资产并收取佣金。
